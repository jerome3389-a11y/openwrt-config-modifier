Drop an OpenWrt config export here 把从路由器导出的配置文件拖到这里

Every parameter is parsed, explained, checked for logic errors and conflicts — each one editable in exactly one place — then exported back as a clean uci batch script. Everything runs locally in your browser; nothing is uploaded. 全部参数解析、说明、逻辑排错，每个参数只有一个可编辑位置，最后生成干净的 uci batch 脚本导回路由器。所有处理都在浏览器本地完成，不上传。

How to export from the router 如何从路由器导出

  • LuCI: System → Backup / Flash Firmware → Generate archive (a .tar.gz — drop it here directly) LuCI 备份包可直接拖入
  • SSH, one file with everything: 一条命令导出全部 UCI
uci export > /tmp/router.conf
# or per package:
uci export network > network.conf

Accepted formats 支持的格式

  • uci export output (all packages in one text file) 全量导出文本
  • Individual files from /etc/config/ — select several at once 可多选
  • sysupgrade -b backup .tar.gz 系统备份包
  • uci show output show 格式

What the analyzer checks 逻辑分析会查什么

  • WAN firewall zone left open, open Wi-Fi, weak keys 防火墙与无线安全
  • noresolv with no upstream DNS, DNS defined in conflicting places DNS 冲突
  • DHCP pool overflowing the subnet 地址池越界
  • IPv6 prefix over-commitment, RA switched off IPv6 前缀与 RA
  • PPPoE MTU, timezone mismatch, missing NAT… 等十余项规则
⚠ Review before you apply. The generated script changes the router the moment it runs. Keep a backup (sysupgrade -b) and, for network changes, apply with a rollback plan — a wrong network value can lock you out. 执行前请先核对并备份；network 改错可能把自己锁在路由器外，建议预留回滚手段。
